Reading Slider

Extract the ZIP while keeping the folder structure intact.
Copy your local KGPrimaryPenmanshipAlt.ttf into assets/fonts/.
Open index.html. If local font loading is blocked, use a local web server.

The custom font applies only to the reading text. Word widths are measured
after the font loads. Arial is used if the font is unavailable.

Custom CSS and JavaScript are separate local files. Bootstrap and jQuery
remain CDN dependencies and require internet access.

The font itself is NOT included. Supply your own licensed copy.
Sentence splitting is punctuation-based; abbreviations may cause page breaks.
This project has not been browser-tested.
